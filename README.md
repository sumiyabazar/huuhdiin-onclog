## 🚀 Локал орчинд

```
npm install
npm run dev
```

`http://localhost:5173` нээх.

## 🌐 Vercel deploy

1. GitHub repo үүсгэх, кодыг push хийх
2. vercel.com дээр GitHub-аар нэвтрэх
3. "New Project" → repo сонгох
4. Environment Variables нэмэх:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_KEY`
5. Deploy
